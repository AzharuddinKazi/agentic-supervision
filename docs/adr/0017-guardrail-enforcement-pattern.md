# Guardrail enforcement is a pattern applied to every agent, not a one-off rule for Gap Analysis

An independent architecture review (`.scratch/architecture-review-2026-09-15.md`, Critical Finding #1) found that ADR-0004's citation-grounding rule was the only guardrail actually enforced in code — every other agent's risk of producing an ungrounded or unvalidated assertion had no equivalent protection. Two concrete gaps existed: Findings & Reporting Agent's `severity` output was never checked against `severity_rubric.lookup()`'s actual return value before being persisted, and AG & Pre-Exit Agent's "LLM may assist in summarizing AG feedback" path fed straight into a Findings & Reporting redraft trigger with no grounding requirement at all — reintroducing, downstream of the human-sign-off checkpoint the whole system depends on (ADR-0003), the exact hallucination risk ADR-0004 was written to prevent.

We're generalizing ADR-0004 into a standing pattern: **any agent output that claims to be derived from an authoritative source (a rubric, a tool result, another human's stated feedback) must be code-verified against that source before being persisted or acted on — never trusted because the agent's narration says so.** Two concrete instances fixed under this pattern:

1. **Severity validation (Findings & Reporting Agent).** Persisted `severity` must equal the last `severity_rubric.lookup()` return value for that finding, or the write is rejected. This is a code-level assertion, not a prompt instruction.
2. **AG-feedback grounding (AG & Pre-Exit Agent).** The LLM-generated summary of AG feedback is never passed directly to Findings & Reporting as a redraft trigger. It first surfaces to the Lead/Approver as its own reviewable artifact, behind its own `interrupt()` — see `lfi-workflow-phase3-postexam-v1.html`'s "AG Feedback Review" node. Only human confirmation triggers the redraft.

This is worth recording as its own ADR rather than folding into ADR-0004, because the pattern — not just the citation case — is the thing future agents must be checked against. Any new agent added to this pipeline should be reviewed for "does this agent narrate something it should instead be forced to prove," and that review should cite this ADR.
